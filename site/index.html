agent.kompo.se

Muse, LYTD and KLI — in a box. The agent-first client for kompo.ai: tools for efficient creation of music videos where your LLM augments you, from the CLI, in the context of your music/video project.

🔐 Access is invitation-only. If you would like early access, please open an issue on the GitHub repository.

Install & quickstart

The @kompo/kli CLI package is publishing soon — it is not yet available on npm. KLI runs on Bun. Once published, getting started will be:

bunx @kompo/kli help
# or: npm install -g @kompo/kli  # Bun is still required

Then, inside a project directory:

kli init
kli auth/url    # prints a PKCE login URL to open in a browser
kli auth/complete <callback-url>

The CLI authenticates against the kompo.ai service (your persisted kompositions, audio/video content, semantic graph, video builds) — no web UI required. The system is self-describing via KCP: an agent discovers the domain, the available tools, and the server-side API, then works your project directly.

The six workflows

  1. 1
    Bootstrap & discovery The tools manifest describes every callable operation, its HTTP method, path, and input schema. kli init fetches the knowledge manifest and writes agent-readable project context.
  2. 2
    Authentication PKCE paste-back login via kli auth/url → kli auth/complete <callback-url>. No cloud credentials leave your machine.
  3. 3
    Upload Upload audio, video, and image files to your media library via presigned S3 URLs.
  4. 4
    Analyze & tag kilder Metadata extraction (BPM, beat grid, MusicDNA) creates tagged Kilder — reusable media source catalog entries with segment definitions.
  5. 5
    Compose a komposition Create a markdown document (komposition) describing your music video: BPM, beat timings, visual tracks, and which kilder to use. Compose via natural-language chat or the CRUD API directly.
  6. 6
    Build, poll & download Submit the komposition for rendering. Poll job status (PENDING → RUNNING → SUCCEEDED) and download the finished .mp4.

Agent discovery

This site exposes the Knowledge Context Protocol (KCP) manifest so that LLM agents can discover the kompo.ai domain, tools, and API automatically.

KCP Manifest
/knowledge.yaml
Unit bodies
/docs/kcp/<unit>.md

Each unit in knowledge.yaml has a path field pointing to its markdown documentation under docs/kcp/. Agents should first fetch /knowledge.yaml, then follow the unit paths.
